## 1. The 8 × CS7036 `Thickness` errors — real repo defect, FIXED (round-6 commit)

The list's only `(active)` compiler errors were 8 × CS7036
"no argument given that corresponds to the required parameter 'right' of
'Thickness.Thickness(double, double, double, double)'" at
`Theme/step1.g.Customization/step1.g.9.PageSizeService.cs` lines 43, 44, 47,
48, 51, 52, 55, 56.

**Root cause (verified against the WPF reference source,
`dotnet/wpf` release/8.0 `Thickness.cs`): WPF `Thickness` has NO 2-argument
constructor.** The full constructor set is:

```
Thickness()
Thickness(double uniformLength)
Thickness(double left, double top, double right, double bottom)
Thickness(Size size)
Thickness(Size horizontal, Size vertical)
```

The file used 8 two-argument calls — `new Thickness(10, 5)`,
`new Thickness(8, 4)`, … — one pair per size layout. Each 2-arg call
best-matches the 4-arg constructor, missing the 3rd parameter `right` —
exactly the reported error text, on exactly the 8 reported lines.

**Correction of record:** the round-5 audit in this document originally
claimed "12 × 2-arg — valid" and concluded the errors came from a locally
modified file on the build PC. **That was wrong.** The build PC's working
tree was clean and byte-identical to the repo (owner's `git status` proved
it). The defect was real and in the repo; the audit counted argument
arities but asserted validity without checking that a 2-arg `Thickness`
constructor exists. Corrected here and enforced in §6.

**Fix:** each `new Thickness(a, b)` (intended symmetric horizontal/vertical
margin) is now `new Thickness(a, b, a, b)` — 8 calls, lines 43, 44, 47, 48,
51, 52, 55, 56.

## 6. Standing rule reminder

Per docs/02 (only standard WPF APIs) and docs/03 step 3, extended by the
round-5/6 Thickness incident: the pre-commit gate must include a
**constructor-arity audit** — for every `new WpfType(...)` call, the
argument count must be checked against the type's constructor set in the
**dotnet/wpf reference source** (not against memory). The round-5 failure
mode was counting arities and asserting validity without checking the
reference: `Thickness(double, double)` does not exist, and "it looks like
it should" is not verification.
