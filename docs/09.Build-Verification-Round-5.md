## 6. Standing rule reminder

Per docs/02 (only standard WPF APIs) and docs/03 step 3: the pre-commit gate
must include a **constructor-arity check** (e.g. no `new Thickness(a, b, c)` —
WPF has 1/2/4-arg forms only) and a **worktree-clean check** before trusting a
build result — a locally modified file silently swaps committed code for
uncommitted code and produces errors that "do not exist in the source".
